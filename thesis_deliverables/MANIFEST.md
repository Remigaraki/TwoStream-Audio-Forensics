# Thesis deliverables manifest

Everything in this folder is derived from the **corrected** tables on `main`
(post `fix/mcnemar-discrepancy`, merged at commit `354134b`). All source data
is `results/tables/*` and `results/figures/*` on that commit — nothing under
`results/` was modified to build this folder, and no `results/preds_*.csv`
file was touched at any point.

Regenerate the copied/verbatim tables and figures with `scripts/build_results.py`
(reads `results/preds_*.csv`, writes `results/tables/`, `results/figures/`).
Two files in this folder are *not* reproducible from that script alone —
`table_mcnemar.md` (reformatted) and `table_a1_vs_a0_chi2.csv/.md` (new) — see
their rows below for how they were built. Those steps currently exist only as
one-off scripts run for this delivery, not as checked-in code; flagged as a
reproducibility gap at the end of this file.

## Reproducibility gap

Three of the artifacts above (`table_mcnemar.md`'s reformatting, `table_a1_vs_a0_chi2.*`,
`degradation_curve_mindcf_log.png`) were built with one-off scripts run during this
session, not committed to `scripts/`. If you want this folder to stay reproducible
by re-running a checked-in script (matching how `scripts/build_results.py` covers
everything else), say so and I'll fold those three steps into a committed script
rather than leaving them as this session's scratch work.
